# Life Vault Explorer

An interactive Conway's Game of Life simulator with a library of known patterns.

## Features

- Clickable grid for toggling cells
- Play/pause, single-step and clear controls
- Adjustable simulation speed and generation counter
- Pattern library with still lifes, oscillators and spaceships (e.g. Glider, Pulsar, LWSS/MWSS/HWSS)
- Info panel explaining the rules

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```
